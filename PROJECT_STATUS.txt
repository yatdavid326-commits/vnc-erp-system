───────────────────────────────────────────────────────────────────────────────
💡 TIPS Y BUENAS PRÁCTICAS
───────────────────────────────────────────────────────────────────────────────

1. SEGURIDAD:
   - Nunca commitear .env.local al repositorio
   - Mantener credenciales en variables de entorno
   - Actualizar permisos RLS cuando sea necesario

2. DESARROLLO:
   - Hacer commits pequeños y descriptivos
   - Testear localmente antes de hacer push
   - Usar ramas para features grandes

3. DEPLOYMENT:
   - Verificar build localmente: npm run build
   - Un commit = un deploy automático
   - Rollback disponible en Vercel si hay error

4. BASE DE DATOS:
   - Supabase hace backups automáticos
   - Mantener índices en columnas consultadas
   - Monitorear performance en Dashboard

5. PERFORMANCE:
   - Ver analytics en Vercel Dashboard
   - Verificar logs en Supabase
   - Usar lazy loading para componentes
